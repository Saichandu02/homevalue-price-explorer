# Verification — what actually ran (2026-10-31, this VM)

Environment: Python 3.12.3, 4 cores, ~8 GB RAM shared, Linux. Verified dependency
versions: pandas 2.2.3, numpy 2.1.3, scipy 1.14.1, scikit-learn 1.5.2, Flask 3.0.3,
pytest 8.3.3. **No Docker on this VM** — Dockerfile/docker-compose.yml are
configuration only, inspected but not executed. Public deployment: not attempted
(no authorized account).

Validation: 20,640 raw rows → 20,640 modelled (0 exact duplicates, 0 dropped).
Splits (GroupShuffleSplit by 0.1° lat/lon grid, seed 42): train 14,412 /
validation 3,755 / test 2,473. Preprocessing fit on train only.

Winner test slices (MAE USD): price band <150k: 26,257 (n=843) · 150–250k: 30,847

itself is truncated. Residual percentiles (test): p5 −74,392, median −5,274,
p95 +112,974. Full per-row residuals: `artifacts/residuals.csv` (regenerated).

## 4. Latency — `scripts/benchmark.py http://127.0.0.1:8101 100`

Warm-up 10 discarded, n=100 sequential requests, concurrency 1, Flask dev server
on this 4-core VM: **mean 111.42 ms, p50 106.29 ms, p95 191.25 ms** per
`/api/predict` call (includes HTTP + 200-tree inference + SQLite history write).

## 5. Persistence / restart

Server killed and restarted *without* retraining: `/readyz` 200 again, prediction
history in SQLite survived (rows from the benchmark run were still returned by
`/api/history`), and the same sample payload returned the identical price
250328.61 — train/serve determinism confirmed in practice.
